# Course_Portal
A school project focused on developing a comprehensive online portal where students and teachers can securely sign in and access relevant academic tools and resources.

## HOW TO RUN

1. Make sure you have Python (latest version) installed.

2. Download the project files.

3. Open the main script in Python and run it.
